# **Fins-McCool.github.io**
## ***Yearly Planner***

***This application includes:***

- A calendar with customizable tasks.
  - Multiple tasks can be in one day! 
- Cute colours.

***How to use this application:***
1. Click on date that needs a task added.
   1. A text box will come up for the task.
2. Put task in text box.
   1. When viewing the whole calendar, one can see all tasks that have been added.
